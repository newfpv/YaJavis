# Аккаунты ChatGPT и лимиты

В «Подключения → Подписка ChatGPT» можно сохранить до восьми аккаунтов. Кнопка «Добавить аккаунт» открывает обычный вход по коду. Повторный вход в тот же аккаунт обновляет его авторизацию, сохраняя локальную статистику. Существующий одиночный вход переносится автоматически.

«Сделать активным» переключает аккаунт для новых запросов и закрывает текущий разговор. Удаление активного аккаунта выбирает первый оставшийся; удаление последнего отключает вход. Локальная память ассистента общая. Идентификаторы облачных разговоров разделены по аккаунтам.

## Автопереключение

Галочка «Автоматически переключать аккаунт» по умолчанию выключена. Если она включена, подтверждённый отказ из-за лимита, недействительной авторизации или отсутствия доступа позволяет попробовать следующий доступный аккаунт в порядке списка. При HTTP 401 сначала выполняется обновление авторизации.

Таймауты, сетевые ошибки, HTML-страницы блокировки и неопределённый HTTP 403 не переключают аккаунт. Попытки ограничены количеством сохранённых аккаунтов. После начала потокового ответа запрос не повторяется на другом аккаунте, чтобы не дублировать ответ и вызовы инструментов. Если ошибка получена внутри голосовой сессии, она закрывается; выбранный запасной аккаунт используется при следующем открытии разговора.

Ограничения GPT-Live и текстовых запросов Codex хранятся отдельно для каждого аккаунта. При голосовом лимите можно продолжать текстовые запросы с тем же аккаунтом. Отзыв авторизации затрагивает оба режима.

## Пятичасовые и недельные лимиты

Свёрнутая карточка показывает сроки сброса, раскрытая — использованную и оставшуюся долю, кнопку обновления и действия с аккаунтом. Данные обновляются раз в минуту; одновременные запросы объединяются. Проверка не меняет выбранный аккаунт и не открывает голосовое соединение.

Это лимиты **Codex**, полученные из ответа ChatGPT `/backend-api/wham/usage`. Они не показывают остаток голосового времени GPT-Live. Если ответ не содержит окна или срока сброса, панель показывает отсутствие данных. Локальная пауза перед повторной попыткой не выдаётся за срок восстановления квоты. При ошибке обновления ранее полученные значения остаются с предупреждением.

## Статистика GPT-Live

Для каждого аккаунта отдельно сохраняются число голосовых соединений, время соединения, длительность отправленного и принятого аудио и подтверждённые отказы из-за лимита. Отправленное аудио включает цифровую тишину. Это локальные счётчики, а не показания биллинга или остаток квоты OpenAI.

Счётчики записываются примерно раз в минуту и при закрытии соединения. При отключении питания возможна потеря последней несохранённой минуты. Аудиозаписи, расшифровки и токены в статистике не сохраняются.

## Хранение и совместимость

Авторизация остаётся в закрытом хранилище настроек. В API панели передаются только сводка аккаунтов, состояние лимитов и статистика. Обновление токенов проверяет, что аккаунт не сменился и не был удалён во время запроса. Временная установка старой версии может скрыть карточки; при возврате текущая авторизация сверяется с сохранённым аккаунтом, чтобы не восстановить устаревший refresh token.

Проверка лимитов использует внутренний endpoint ChatGPT: формат и доступность ответа могут измениться на стороне сервиса.
